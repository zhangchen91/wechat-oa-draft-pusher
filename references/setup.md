# 公众号接入前置准备（管理员操作）

本 Skill 只负责「把文章推送到草稿箱」，调用微信公众平台接口需要以下 4 样东西。请由**公众号管理员本人**操作。

## 1. 一台装了 WorkBuddy 桌面端的电脑

桌面端才能读取本地文章、处理图片并调用接口。本 Skill 在 macOS / Windows 桌面端验证可用。

## 2. 一个已认证的微信公众号

需管理员权限，用于后续扫码启用 AppSecret、修改 IP 白名单。订阅号、服务号均可，但必须已完成微信认证（否则很多接口不可用）。

## 3. 获取 AppID 和 AppSecret

1. 浏览器打开微信公众平台（mp.weixin.qq.com），用管理员微信扫码登录。
2. 左侧菜单【设置】→【公众号设置】→【基本配置】（或开发者凭据页）。
3. 找到 **AppID**（公众号的「身份证号」）。
4. 点击「启用」**AppSecret**，管理员扫码授权后生成。**AppSecret 只显示一次**，立即复制并保存在安全位置，关掉页面就再也看不到，只能去重置。
5. 把 AppID 与 AppSecret 提供给 WorkBuddy（对话里直接给，或写入本地 `config.json`，不要提交到任何仓库）。

## 4. 配置 IP 白名单（最容易卡的一步）

微信为保证接口安全，除了凭证正确，调用接口的公网 IP 也必须提前登记。

- 首次调用时若报 `40164`，WorkBuddy 会回显一个出口 IP。
- 复制该 IP，回到微信公众平台【设置】→【公众号设置】→【IP白名单】→ 添加并保存。
- 添加后重新运行，微信不再返回 `40164` 即配置正确。

> 提示：如果在云服务器/不同网络环境下运行，出口 IP 可能变化，需要时把新 IP 加入白名单即可。

## 5. 验证链路是否跑通

用本 Skill 的 `--dry-run`（只取 token + 上传图片，不创建草稿）先验证凭据与白名单，确认无误后再正式推送。跑通 1.0 即可，不必一开始就追求完美排版。
